# To-Do List da terminale (Python)

Un semplice programma in Python per gestire una lista di cose da fare tramite il terminale. I dati vengono salvati su un file chiamato `attivita.txt`.

## Come si usa

1. Apri`/to-do-list-py-ita` nel CMD
2. Esegui `python .\todo.py` nel CMD
3. Segui il menu per aggiungere, rimuovere o visualizzare attività
4. Le attività vengono salvate automaticamente

## Requisiti

- [Python 3 installato](https://www.python.org/downloads/)
